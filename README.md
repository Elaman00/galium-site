# Сайт GALIUM — инструкция

Лендинг-магазин медицинской одежды GALIUM. Чистые HTML + CSS + JS, без сборки и зависимостей.
Тексты, цвета, модели, цены и контакты взяты из **Brand Book GALIUM 2026**. Добавлены данные Kaspi.kz (ARU FLOW, рассрочка на 3 месяца) и Instagram @galium.kz (скидка студентам, марафон).

```
galium-site/
├── index.html        — разметка и тексты (разделы подписаны комментариями)
├── css/style.css     — стили; фирменные цвета — в начале файла (:root)
├── js/main.js        — логика; НАСТРОЙКИ в самом верху: CONFIG, COLORS, SIZES, PRODUCTS
├── assets/           — логотип (logo-red/white.png), фавиконы
│   └── products/     — фото товаров (брендбук, Kaspi.kz, Instagram)
└── serve.js          — локальный сервер для проверки
```

## 1. Как запустить
- Проще всего: дважды кликните `index.html`.
- Как на настоящем хостинге (нужен Node.js): в папке `galium-site` выполните `node serve.js` и откройте http://localhost:5173

## 3. Товары, цвета, размеры, цены
Всё находится в начале `js/main.js`:
- `COLORS`: 6 цветов из брендбука с HEX-кодами (Royal Blue, Navy Blue, Black, Cobalt Blue, Mint Green, Carbon Grey). Палитра на сайте строится из этого списка.
- `SIZES`: буквенная сетка XS–XXXL. Размер по умолчанию задаётся в `DEFAULT_SIZE`.
- `PRODUCTS`: 3 карточки.
  - ARU FLOW · Henley: женская, цвета Black, Royal, Navy.
  - V-Neck: унисекс, крой женский или мужской, брюки Jogger или Straight, цвета Royal, Navy, Black, Cobalt, Mint.
  - Carbon Grey: мужской меланж.
  - В каждой карточке есть `fits` (крой) и `pants` (брюки). Если вариант один, выбор не показывается.
- **Цены**: базовая цена комплекта 35 000 ₸. Рассрочка `installmentMonths: 3` (11 667 ₸/мес).
- **Скидки**: студентам −10%; опт −10% от 20 единиц (`bulkFrom`); от 100 единиц цена по договорённости (`customPriceFrom`). Корзина применяет одну скидку, большую из двух, и не суммирует их.

**Фото**: `assets/products/`, пропорция 4:5. Чтобы заменить фото, положите файл в папку и впишите его имя в `photos` нужного товара. Второе фото в списке показывается при наведении.
Кадры Mint Green сейчас показывают только детали (воротник, карман), фото модели в мятном в брендбуке нет. Пришлите его, и я поставлю.

## 4. Отзывы
Придуманные отзывы с сайта убраны: публиковать их как настоящие нельзя. Вместо них блок «Проверено в деле» с фактами из брендбука и кнопка «Отзывы клиентов — в Instagram». Когда появятся реальные отзывы с разрешением клиентов, их можно добавить туда же, в `<!-- ПРОВЕРЕНО В ДЕЛЕ -->`.

## 5. Как работают формы
**Сейчас, без настройки**, после отправки форма показывает кнопку «Отправить заказ в WhatsApp» (или «Написать в WhatsApp») с готовым текстом: товары, размеры, крой, сумма, имя и телефон клиента. То есть заявки уже доходят до вас через WhatsApp, если клиент нажимает эту кнопку.

Чтобы заявки приходили **автоматически**, подключите один из способов в `CONFIG`:

**A. Formspree (заявки на почту)**
1. Зарегистрируйтесь на https://formspree.io и нажмите «New form» (укажите zhenisgaliyev@gmail.com).
2. Скопируйте адрес вида `https://formspree.io/f/abcdwxyz`.
3. Вставьте его в `CONFIG.formspreeEndpoint`.

**B. Telegram-бот**
1. В Telegram напишите @BotFather, команду `/newbot`, и получите токен.
2. Напишите своему боту любое сообщение, откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}`.
3. Впишите `telegramBotToken` и `telegramChatId` в `CONFIG`.
⚠️ Токен будет виден в коде сайта. Заведите отдельного бота только для заявок.

## 7. Другие варианты хостинга
**Netlify (быстрее всего):** откройте https://app.netlify.com/drop и перетащите папку `galium-site`. Домен galium.kz подключается в Site settings → Domain management.

**Vercel:** https://vercel.com → Add New → Project → загрузите папку или подключите GitHub-репозиторий. Framework: «Other».

**GitHub Pages:** создайте репозиторий, загрузите содержимое `galium-site`, затем Settings → Pages → Branch: `main` / root.

После публикации: если адрес сайта не galium.kz, замените `https://galium.kz/` в `<head>` (canonical, og:url, og:image). Превью ссылки в мессенджерах уже настроено (`assets/products/og-cover.jpg`).
